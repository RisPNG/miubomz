# Desktop experience

Miubomz supplies a familiar GNOME desktop with a bottom panel, application menu, tray icons, desktop icons and window controls. Fluent themes, icons and cursors provide a consistent appearance. GNOME preferences remain editable; the distribution does not lock settings against user changes.

The desktop starts with the selected extensions enabled, including Dash to Panel, ArcMenu, Desktop Icons NG, Blur My Shell, Tiling Assistant, AppIndicator support, Just Perfection and the supplied utility extensions. Their exact versions belong to the Miubian software lock. Monitor configuration must work on the installed machine rather than retain a reference display identifier.

Keyboard shortcuts, file-manager actions and terminal integration follow the documented setup. New accounts receive the defaults once. Package updates must preserve preferences that a user subsequently changes.

Miubian implements these choices in `variants/miubian/integration/defaults/gnome/`, application and shell defaults, and the shared account initializer. Upstream themes and extension code are software inputs rather than maintained Miubomz implementations.
